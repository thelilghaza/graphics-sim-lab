# Project 07: WebGPU 3D Engine

*Status: Planned (Phase 0 Documentation Placeholder)*

## Overview
A modern web-native 3D graphics engine written in WebGPU/WGSL, featuring Physically Based Rendering (PBR), glTF asset loading, and WebAssembly integration options.

## Objectives
- WebGPU render pipeline with WGSL shaders.
- Standard metallic-roughness PBR model.
- Async glTF 2.0 asset loader and scene parser.
